Uma pequena tentativa de criar uma engine 3D inspirada em engines como Unity e Godot, utilizando SDL.

O projeto foi desenvolvido principalmente como uma forma de aprender, na prática, os fundamentos por trás de uma engine 3D: renderização, gerenciamento de objetos, transformações, câmera, colisões e outros sistemas.

Embora não tenha chegado a se tornar uma engine completa, os conceitos e experiências adquiridos aqui estão sendo utilizados em um projeto mais recente, no qual estou desenvolvendo minha própria engine utilizando Macroquad como base para continuar explorando esses conceitos.
